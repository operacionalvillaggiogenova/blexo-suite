# Blexo Suite — Login com Google

A aplicação já está configurada com o OAuth Client ID do projeto Blexo Suite.

Para o usuário:
1. Abra Configurações.
2. Clique em **Conectar Google Drive**.
3. Escolha a conta Google.
4. Faça login na página oficial do Google, se necessário.
5. Autorize o acesso solicitado.
6. Volte ao Blexo Suite com a conta conectada.

O Blexo não solicita, recebe ou armazena a senha do Google.
