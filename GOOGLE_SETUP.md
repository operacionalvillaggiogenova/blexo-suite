# Google Drive
1. Ative a Google Drive API no Google Cloud.
2. Crie OAuth Client ID para Web.
3. Cadastre a origem onde o Blexo será hospedado.
4. No Blexo Suite, abra Configurações, informe o Client ID e conecte o Google.
5. O módulo Orçamentos sincroniza JSONs em Blexo Suite/orcamentos.

Os módulos existentes foram mantidos como base. A migração completa de Check/Leiturista/Scanner para Drive deve ser feita em seguida, módulo a módulo, para evitar a quebra que ocorreu antes.
